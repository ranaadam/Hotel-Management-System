# Hotel Management System

A desktop application developed to streamline hotel guest management operations through a simple and efficient interface. The system enables hotel staff to manage guest records, monitor check-ins, perform guest searches, and process check-outs using a connected MySQL database.

## Overview

This project was developed using C# and Windows Forms with MySQL for data storage. The application focuses on providing reliable guest management functionality while maintaining a clean and user-friendly desktop experience.

## Core Functionality

- Guest registration and record management
- Guest search by name or room number
- Check-out processing
- Real-time data retrieval
- Input validation and error handling
- Database connectivity and management

## Technologies

- C#
- Windows Forms (.NET)
- MySQL
- MySql.Data.MySqlClient

## Architecture & Design

The system follows a monolithic architecture where the user interface, application logic, and database operations are integrated within a single desktop application.

The project was developed following the Waterfall Software Development Model, including requirements analysis, system design, implementation, and testing phases.
